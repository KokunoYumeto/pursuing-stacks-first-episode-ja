## 検証と限界

完全性台帳は425区分を覆い、翻訳必須178区分・原典1,796,962バイトの未解決区分は0である。
本文・前付・付録に対する423件の原典投影検査は423件すべて合格した。モジュール版PDFは
同一条件の二回のビルドで生バイトまで一致した。直接累積LaTeXも独立した二回のビルドで
生バイトまで一致した。二つのソース構成から得たPDFは、539ページ、二方式の全文抽出、
および21枚の代表ページの画素が一致する。二つのPDF自体には内部直列化による8バイトの
差があるため、異なるソース構成間の生PDF同一性は主張しない。

全フォントは埋込み・部分集合化され、日本語フォントにはToUnicodeがある。抽出上の代替文字
2個は同一の数式中のリングアクセントに由来し、299ページの表示は正常である。代表ページの
目視では、切れ、重なり、豆腐文字、判読不能な字形を認めなかった。

本日本語訳の翻訳・校訂は OpenAI Codex — GPT-5.6 Sol（Ultra 推論強度）によって
行われた。人間の専門家による査読・校閲は受けていない。したがって、訳語、構文、歴史的な
含意、数式周辺の説明に誤りが残る可能性がある。機械的検査は完全性、構造、再現性、抽出・
表示上の欠陥を減らすが、人間の専門判断を意味しない。
